# Staff procedure: handling a refused COD parcel

Internal. Not for customers.

1. When the courier marks a parcel refused, set the order status to `refused` the same day.
2. Call the customer once to ask why, and record the reason in the order notes.
3. If the reason is valid (damaged parcel, wrong item, or delivery later than the promised window), take no action against the customer.
4. If there is no valid reason, flag the customer as **advance-only**. Their next order needs full payment in advance.
5. When the parcel comes back, inspect it within 1 working day. Return it to stock, or set it aside if it is damaged.
6. Record the two-way delivery cost against the order for the monthly loss report.
