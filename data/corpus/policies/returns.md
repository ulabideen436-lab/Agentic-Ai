# Returns policy

## Return window
You can return an item within **7 days** of receiving it.

## Condition required
The item must be unused, unwashed and in its original packing, with every piece of the set included. A 4-piece set comes back as 4 pieces. We cannot accept part of a set.

## Items we do not take back
- Items that have been used, washed or stitched.
- Razai, gadda and pillows once the plastic packing is opened, for hygiene reasons.
- Cloth cut to length, such as curtain cloth or fabric sold per metre.
- Items bought on clearance or marked "final sale".

## Who pays return shipping
If the item is faulty, damaged or not what you ordered, **we pay** the return shipping. If you changed your mind, **you pay** the return shipping, and the original delivery charge is not refunded.

## How to start a return
Message us on WhatsApp with your order number and a photo of the item. We reply with the return address or arrange a pickup.

## Exception: wrong size ordered
A wrong size is handled as an **exchange**, not a return. See the exchange policy.
