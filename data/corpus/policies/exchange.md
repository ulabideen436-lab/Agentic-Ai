# Exchange policy

Most bedding exchanges are about size, so this policy is mainly about size.

## Size exchange
You can exchange an item for a different size of the **same product** within **7 days** of receiving it. The item must be unused, unwashed and in its original packing, with all pieces.

## Price difference
If the new size costs more, you pay the difference. If it costs less, we refund the difference by the same method as a normal refund.

## Exchanging for a different product
This is allowed within the same 7 days, on the same conditions. The price difference is settled the same way.

## Delivery charges on an exchange
If we sent the wrong size, we pay delivery both ways. If you ordered the wrong size, you pay delivery for the replacement parcel.

## Exception: the size you want is out of stock
You can choose another product, wait for a restock, or return the item for a refund under the returns policy.
